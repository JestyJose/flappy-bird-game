# 🐦 Flappy Bird

A browser-based Flappy Bird game built using HTML, CSS, and vanilla JavaScript with HTML5 Canvas.

## 🎮 Live Demo

[Play Flappy Bird](https://jestyjose.github.io/flappy-bird-game/)

## ✨ Features

- Bird movement with gravity and flap mechanics
- Moving pipe obstacles
- Randomly generated pipe gaps
- Collision detection
- Score tracking
- Start screen
- Game Over and restart system
- Animated bird rotation
- Collision particle effects
- Cartoon-style environment
- Responsive gameplay controls

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas

## 🎮 Controls

- **Spacebar** — Flap / Start / Restart
- **Mouse Click** — Flap / Start / Restart
